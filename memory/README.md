# Memory index

Shared, durable project knowledge lives in Git. Session memory is temporary; only reviewed and committed knowledge is durable.

## Files

- `current-state.md` — current approved phase, active work, recent PRs/commits, blockers, next step.
- `phase-roadmap.md` — phase list and exit criteria.
- `phases/phase-0.md` ... `phases/phase-5.md` — per-phase objectives, exit criteria, dependent tasks, status, decisions, risks, evidence.
- `decisions/` — decision summaries linking to ADRs.
- `daily/YYYY-MM-DD.md` — daily reports.
- `lessons-learned.md` — reusable lessons.

## Conventions

- Distinguish approved fact / proposal / assumption / open question / observed result.
- Never promote a guess into approved knowledge.
- Cross-link files; keep files small and purpose-specific.
