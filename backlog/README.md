# Backlog

## Purpose

The Hamtayar backlog originates in the WBS workbook `Hamtayar_Backlog_WBS.xlsx`. This directory holds the **source manifest**, **normalized reproducible exports**, and **open questions**. The workbook itself is a planning baseline, not evidence of completion.

## Authoritative task status

**Not yet decided.** Candidate sources: GitHub Issues/Projects (this repo) or Jira (referenced by the WBS). Until the team agrees, this repository does **not** create 442 duplicate Issues and does **not** synchronize with Jira. Observed status changes are recorded in `memory/` with source and date. See `open-questions.md` (OQ-STATUS).

## Files

- `source-manifest.md` — where the authorized sources live and their classification.
- `open-questions.md` — traceable list of decisions/unknowns (from the WBS "Open Questions" sheet plus project-level).
- `normalized/` — reproducible exports derived from the WBS (JSON + CSV), generated by `scripts/ingest_wbs.py`. Never edit by hand; regenerate.
